BECCATE STO' PIATTO — PWA v0.1

Installazione senza computer:
1. Estrai lo ZIP sul telefono.
2. Crea un repository pubblico gratuito su GitHub (es. beccate-sto-piatto).
3. Carica i cinque file della cartella nella radice del repository: index.html, app.js, sw.js, manifest.webmanifest, icon.svg.
4. Repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Apri l'URL HTTPS fornito da GitHub Pages in Chrome su Android > menu > Installa app o Aggiungi a schermata Home.

IMPORTANTE: Non caricare referti, backup o dati personali su GitHub. L'app salva i dati nel localStorage del browser, non cifrati dall'app. Non è ancora adatta alla conservazione di documenti medici sensibili. La funzione ChatGPT copia un prompt da incollare manualmente in ChatGPT; non usa API e non accede al tuo abbonamento. La PWA è un prototipo personale, non un dispositivo medico.
