Beccate sto' piatto v0.4

NOVITÀ
- Pagina Ricette semplificata: calendario + riepilogo qualità nutrizionale 0–5.
- Storico della bonanza: diario dei pasti effettivamente mangiati, con una foto opzionale per pasto.
- Foto conservate localmente in IndexedDB, ridimensionate dal browser; non inviate a GitHub.

INSTALLAZIONE
Carica i sette file index.html, app.js, calendar.js, bonanza.js, sw.js, manifest.webmanifest e icon.svg nella radice del repository GitHub Pages, sovrascrivendo i precedenti; non caricare la cartella o il file ZIP.

PRIVACY
I dati sono memorizzati nel browser del dispositivo: non costituiscono archivio sanitario cifrato. Le foto NON sono incluse nel backup JSON della versione attuale. Cancellare i dati del sito o cambiare dispositivo può perdere le foto. Il punteggio è una checklist sulla varietà e copertura del piano, NON un'analisi nutrizionale validata.
